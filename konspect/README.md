# konspect — сюда кидай MP3

Положи файлы лекций в эту папку:

`/workspace/konspect/inbox/`

или прямо в:

`/workspace/konspect/`

Потом напиши Грифиту: **«разбери konspect»**

Он:
1. расшифрует mp3 → текст
2. положит конспекты в `griffith/library/audio/transcripts/`
3. выучит и добавит в базу

Уже обработанные можно не дублировать — повторы просто дополнят базу.
